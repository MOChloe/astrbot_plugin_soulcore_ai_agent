- [故障排查](troubleshooting.md)：按实际现象定位配置、适配器、模型与界面问题。
- [更新日志](../CHANGELOG.md)：作者确认后公开的正式版本说明。

## 开发者文档

- [架构说明](architecture.md)：运行边界与主要组件。
- [数据边界](data-boundaries.md)：持久化、会话与展示数据的职责划分。
