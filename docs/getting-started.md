# 快速开始

本页用于把 SoulCore 从“已经安装”带到“可以正常聊天”。日常交流仍在原来的 AstrBot 聊天窗口中完成。

## 1. 安装并打开界面

1. 在 AstrBot 插件市场搜索 **SoulCore** 安装，或通过 GitHub 仓库地址安装。
2. 确认 AstrBot 版本满足插件详情页中的要求。
3. 进入 `插件管理 → SoulCore → 打开插件 UI 界面`。

如果插件没有成功加载，先查看 AstrBot 插件日志，再参照[故障排查](troubleshooting.md#插件没有加载或界面打不开)。

## 2. 选择角色并配置主力文字模型

快速设置会先让你选择或创建角色。随后选择主力文字模型，并执行一次真实文字请求验证连接。

主力文字模型是唯一必需项。它负责普通对话中的判断、行动和最终回复；仅在模型真实调用成功后，快速设置才会把该项视为可用。

快速文字模型可以直接复用主力模型。视觉理解、联网查询、图片生成和回复润色均为可选能力，可以先跳过，之后再从高级设置中补充。

## 3. 完成角色与生活设置

角色资料用于定义角色是谁、如何表达以及需要遵守的边界。快速设置中的角色字段可以按你的材料填写，不要求为了通过流程而虚构内容。

“聊天之外的生活”也是可选项。开启后，SoulCore 可以维护角色当前生活、近期事件与准备做的事；这会增加额外模型调用。第一次使用可以保持关闭，确认基础对话正常后再启用。

主动联系、媒体能力和不同聊天对象的策略同样可以稍后调整。快速设置只需要完成你当前真正要用的部分。

## 4. 回到聊天窗口

完成设置后，回到 QQ、AstrBot WebChat 或当前适配器对应的聊天窗口，像平常一样发送消息。

新会话第一次收到普通消息时，SoulCore 会先创建该会话需要的运行状态，并提示“初始化完成”。触发初始化的那条消息不会继续进入角色回复流程；看到提示后，再发送下一条消息开始聊天。

真实模型的一轮处理可能需要几十秒，并可能分成多条消息发送。等待当前处理结束后再重复发送，避免同一内容被并行处理。

## 接下来可以做什么

- 在角色页面查看当前生活、联系人、相处状态和角色资料。
- 在快速设置中补充视觉、联网、生图等可选能力。
- 在高级设置中调整主动联系、媒体发送和不同聊天对象的策略。
- 阅读[能力说明](features.md)了解每项能力的真实边界。
