# 故障排查

先按你实际看到的现象定位，不要为了“试试看”同时更换模型、适配器和角色配置。每次只改变一个条件，更容易确认根因。

## 插件没有加载或界面打不开

1. 在 AstrBot 插件管理中确认 SoulCore AI Agent 已启用，且版本要求满足插件详情页声明。
2. 查看 AstrBot 启动日志，确认没有依赖安装失败、文件缺失或数据库初始化错误。
3. 从 `插件管理 → SoulCore AI Agent → 打开插件 UI 界面`重新进入，不要复用已经失效的临时页面地址。
4. 若页面仍为空白，刷新一次并检查浏览器控制台与 AstrBot 日志中的同一时间段。

报告问题时提供 AstrBot 版本、SoulCore 版本、安装方式和第一条相关错误；不要只发送最终的空白页面截图。

## 快速设置无法通过模型验证

- 确认选择的是可处理普通文字请求的聊天模型，而不是只支持嵌入、重排或图片生成的模型。
- 检查对应 Provider 在 AstrBot 中是否启用，并确认它能在 AstrBot 原生模型测试中完成一次真实请求。
- 如果主力模型成功、可选能力失败，可以先跳过视觉、联网、生图或润色，完成基础设置后再单独排查。
- 生图测试可能产生实际费用；不要在错误状态下连续重复点击。

## 第一条消息只提示初始化完成

这是新会话的正常生命周期。第一次普通消息用于创建该聊天所需的运行状态，不会继续进入角色回复流程。看到“初始化完成”后，再发送下一条消息。

## 消息长时间没有回复

真实模型处理可能需要几十秒，并可能分成多条消息发送。先等待当前轮次结束，再检查：

1. AstrBot 是否仍在处理该请求。
2. Provider 是否返回超时、限流、余额不足或模型不可用。
3. 当前聊天是否允许 SoulCore 处理，以及适配器是否仍在线。
4. 是否有另一插件同时拦截或改写普通对话链路。

不要因为短时间没有看到回复而连续发送同一条消息，这可能产生并行处理。

## 图片、语音或表情没有生效

媒体链路至少涉及 SoulCore 设置、模型能力、AstrBot 和当前适配器：

- 收到的图片无法理解：检查视觉模型是否配置成功，以及该适配器是否把图片内容交给 AstrBot。
- 无法生成图片：检查生图模型、调用额度和当前聊天的图片发送权限。
- 图片已生成但没发出：检查适配器投递日志和当前聊天策略。
- 语音或表情表现与预期不同：确认当前适配器支持对应消息段，并查看最终出站消息，而不是只看模型文字结果。

## 独立页面状态没有更新

页面展示的是已保存状态，不是聊天窗口的实时镜像。先等待本轮处理完成，再刷新对应页面。若状态仍不一致，记录发生时间、角色、聊天对象和当时执行的操作，然后从诊断入口核对实际模型请求、原始输出、解析与保存步骤。

## 与其他插件冲突

标准注册指令及其插件回复会被 SoulCore 隔离，通常可以正常共存。若另一插件读取或改写对话上下文、接管普通消息或自行维护记忆，先临时停用该插件再复现。只有停用后问题稳定消失，才能把它判断为链路冲突。

## 反馈前的最小信息

- AstrBot 与 SoulCore 版本。
- 使用的适配器和安装方式。
- 可复现的最短步骤。
- 问题发生时间和实际影响。
- 同一时间段的必要日志或脱敏截图。

不要公开 API Key、Token、Cookie、完整私聊记录、数据库文件或包含凭据的配置。可通过 [Issues](https://github.com/MOChloe/astrbot_plugin_soulcore_ai_agent/issues) 提交稳定复现的问题，或加入 QQ 群 `1038479108` 交流。
